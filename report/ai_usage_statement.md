## What AI Assisted With

### Code Generation
- Streamlit dashboard layout and page structure (`app.py`)
- Preprocessing pipeline structure (`src/preprocess.py`)
- Model training scripts (`src/train.py`, `src/evaluate.py`)
- RF+ARIMA hybrid implementation (`src/features.py`)
- Jupyter notebook cell structure

### Design Decisions Suggested by AI
- Leakage prevention: identifying that `precipitation_sum` and `temperature_2m_max`
  must be excluded from features because they define the target variable
- 95th percentile threshold selection for defining "extreme" (22.3 mm rain, 34.6°C temp)
- 5-fold StratifiedKFold for stacking meta-model to prevent target leakage
- Using `shift(1)` before rolling means for lag features to avoid same-day leakage
- `scale_pos_weight` parameter for handling class imbalance in XGBoost/LightGBM
